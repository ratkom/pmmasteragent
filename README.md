# AgentPM — AI-powered project management system

A multi-agent AI system that replicates a full project management office, aligned to the PMI PMBOK 7th Edition and the PMI Code of Ethics and Professional Conduct.

## What this is

AgentPM replaces the manual coordination burden of a project management team with a network of 12 specialized AI agents, each owning a distinct PMBOK knowledge area. The agents communicate through a structured event protocol, integrate with standard team tools, and surface decisions to human PMs through a real-time command dashboard.

The system is not a chatbot layered over a spreadsheet. It is an autonomous reasoning network that monitors project health 24/7, detects deviations before they become crises, routes decisions to the right agent (or human), and maintains a full audit trail aligned to PMI governance standards.
